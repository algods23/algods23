## 🌱 Featured Projects

### Seed2Tree Web — Efres Seedlings

> A regression-based web platform for seedling monitoring and smart commerce, serving farmers and buyers in Davao City.

**What it does:**
- Predicts seedling maturity using a **Random Forest** regression model
- Analyzes plant growth data to support better farming decisions
- Integrates e-commerce to connect farmers directly with buyers
- Supports agricultural innovation in Davao City and surrounding regions
